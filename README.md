# DPro Texts Alternative

This repository provides temporary alternative textbook content while the original image host is unavailable.

## Purpose

Some textbook images are currently unavailable because of an outage on the external image-hosting service. This repository keeps the affected assignment text and reference images accessible from GitHub and GitHub Pages until the original host recovers or the in-house image-hosting system is ready.

## How to Use

Share the GitHub Pages URL with instructors and students. They can open the assignment directly in a browser and refer to the written requirements and replacement images.

## Notes for Maintainers

- Keep assignment Markdown files and their related images together in the same assignment folder.
- Prefer local image paths, such as `images/example.png`, instead of external image-hosting URLs.
- Add new texts to the "Available Texts" table when more alternatives are added.
- Keep this repository focused on temporary textbook access during image-hosting incidents.
